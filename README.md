**Abstract:**
A console-based Java application that automates slot allocation and management across a multi-level parking facility. It models the lot as multiple floors, each holding rows of slots categorized by vehicle type — two-wheeler, car, and heavy vehicle — and supports vehicle entry, exit, and real-time availability queries. Its core strength is intelligent slot assignment: incoming vehicles are automatically directed to the nearest suitable free slot, while occupied slots are released on exit and parking fees are computed from duration and vehicle category. Built with object-oriented design, collections, and input validation, it demonstrates modular, menu-driven interaction, ticket generation, and per-floor occupancy reporting, laying the foundation for a future sensor-integrated smart parking management system.
